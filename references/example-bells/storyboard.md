# Example: "The Bell Ringers" (71.5 s, 16 shots)

A complete film made with this workflow. The narration is 69.6 s; the last 1.9 s is a silent tail for the closing gag. Scene code is in `src/s1.js` .. `src/s5.js`; `src/core.js` is the engine plus this film's own props (bell, ringer, church, barrel).

**Art direction.** Linocut print: navy inks, bone paper, vermilion, gold. No on-screen text anywhere. One recurring character (a small red-robed ringer with a paper face and dot eyes). Motif: eyes - the storm has them, the bishop glares, heaven is a single offended eye. The ending replays the opening gag.

Things to notice:
- Shots 3-6 are one sentence split on its commas.
- Shot 7 has almost no narration and is the simplest picture in the film - a summary diagram and a look to camera.
- Shot 14 changes register on purpose: no jokes, slow motion, small lights.
- Shot 16 reuses the set and the gag from shot 1, so the punchline needs no explanation.
